# Student Result & Grade Calculator

An interactive web page that takes a student's marks in five subjects and calculates total marks, percentage, average, grade and pass/fail status.

## Features
- Name and five subject mark fields with helpful validation (0 to 100)
- Calculate Result and Reset buttons
- Grade and pass/fail rules shown on the page (pass needs at least 35 in every subject)
- Styled result card with animated percentage ring and subject-wise table
- Light/dark theme toggle saved in localStorage
- Print option and responsive layout for phones and desktops

## Technologies
HTML5, CSS3, vanilla JavaScript (DOM manipulation and events)

## Setup
1. Clone the repository
2. Open `index.html` in any browser. No build step is needed.

## Project structure
```
index.html   page structure
style.css    styles, themes and animations
script.js    validation, calculation and interactions
```
